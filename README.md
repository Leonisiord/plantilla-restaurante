# Plantilla web para restaurantes, bares y cafeterías

Plantilla de una página cálida para sitios donde se viene a comer sin prisas.

**Vista previa:** https://carlosdev-demo.netlify.app

## Cómo se usa
Los huecos entre corchetes (por ejemplo `[NOMBRE DEL NEGOCIO]`) se sustituyen por los datos reales del negocio y la web queda lista para publicar.

## Incluye
- Carta con platos destacados.
- Horario y cómo llegar, a la vista.
- Botón de reservar mesa siempre a mano.
- Tema claro y oscuro automático según la configuración del móvil.

## Tecnología
HTML, CSS y JavaScript en un único `index.html`, sin dependencias. Tipografías: Fraunces y Work Sans.
`_headers` incluye `noindex` mientras sea una plantilla de ejemplo.

## Desplegar
Se publica la raíz del repositorio tal cual (sin build).
